# Known bugs the generated-program differential test (tools/progen-diff.sh)
# keeps finding. A finding that matches an entry is reported as known and
# does not fail the run or open an issue.
#
# Format: <class>:<issue>:<extended regex>
#   <class>  the class progen-diff.sh gave the seed, or `*` for any class.
#   <issue>  the open issue tracking the bug: file it first, the entry is
#            the bookmark.
#   <regex>  matched against the finding's evidence: the program, both
#            build logs, and both outputs. It is the bug's signature, so
#            key it on the diagnostic when there is one and on the source
#            shape only when there is none.
#
# Seeds change every night, so an entry names a shape, never a seed. A
# source-shape entry also hides any other bug in a program that contains
# the shape: keep such entries narrow, and delete an entry in the PR that
# closes its issue.
