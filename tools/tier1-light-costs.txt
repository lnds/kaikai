# tier1-light-costs.txt — measured cost of each tier1 light target, read by
# tools/tier1-light-plan.sh to split TEST_LIGHT_TARGETS across CI shards.
#
#   <target> <cpu> <wall>   CPU seconds the target burns, and the wall
#                           seconds it takes inside a slice
#   base <slice> <seconds>  fixed work of the shard that carries that slice
#                           (see the tier1-shard-N recipes in the Makefile),
#                           on a PR that touches the compiler
#   base0 <slice> <seconds> the same on a PR that touches none
#                           (TIER1_SELFHOSTS=0); used instead of `base`
#                           when the plan runs with that flag
#   default <seconds>       cpu and wall of a target not listed here
#   parallelism <n>         CPU seconds a runner gets through per wall second
#                           under `make -j$(TEST_JOBS)`
#   elastic <target>        a target that fans its own work out (per-fixture
#                           make targets, an xargs pool): its wall time is
#                           its share of the runner, not a serial floor, so
#                           the plan counts only its CPU
#
# Seconds are on the tier1 CI runner (ubuntu-latest, 4 vCPU). CPU time adds
# up across the targets of a slice and wall time does not, so the plan sums
# the first and takes the maximum of the second.
#
# Do not edit the rows by hand: tools/tier1-light-costs-refresh.sh rewrites
# the bases and the target rows from the logs of green tier1 runs, and
# prints what each slice's measured utilisation says `parallelism` should
# be. Refresh when a shard drifts well past its planned time.
