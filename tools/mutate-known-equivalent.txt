# Known-equivalent mutants — mutations that mean exactly what the
# original meant and so can never be killed.
#
# A suppression here removes a mutant from the run. That is only honest
# when the mutant is genuinely equivalent, so every entry states WHY in
# its own words. An entry without a reason is a hard error, not a
# suppression: one nobody justified is indistinguishable from a hole
# somebody hid, which is the same discipline the coverage matrix applies
# to its `N/A:` rows.
#
# Format, one per line:
#
#   <file>:<line>:<operator>   # why this mutant cannot be killed
#
# `file` is written exactly as `kai mutate` reports it. `operator` is one
# of: arm, compare, connect, negate, literal, call.
#
# This file suppresses; it does not excuse. A mutant that survives
# because the suite has a hole belongs in a fixture, not here.

stage2/compiler/type_scope.kai:67:arm   # the compiler declares no test blocks, so no oracle over its fixture corpus can reach a DTest arm; this is unkillable by construction, not an untested case
