String literals that name text is tested against (extract.py finds them), and why each may be.

  file  fn  test  literal  n  reason  why

  R  a name being resolved: before the resolver, in the parser, or a scalar no declaration stands behind
  D  a diagnostic, a dump, tool output, a test's assertion
  E  emitted text compared to spell output
  L  an operation or field label inside a declaration known by its id

A test that decides which declaration, type, effect or binder something is, after the resolver,
is not listed here: it is a row of pending-written.txt until it is converted to an id.
