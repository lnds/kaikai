# What still breaks the rule: after the resolver, a decision taken on a name's text.
#
#   file  fn  what  why
#
#   what   read            a `written_text` call whose text decides something
#          mint            a reference by text (`EName`, `EModCall`, `mk_name`) built after the resolver
#          <test> <lit>    a literal that name text is tested against (as extract.py prints it)
#
# One row per site. `why` opens with the root cause the site shares with its neighbours:
#   c-local     the C emitter names one local per spelling
#   regs        the KIR lowering keys its register scope by spelling
#   csym        an emitter table is keyed by the emitted C symbol while the FnId is in hand
#   effect-key  an effect instance, frame slot or run-time label is keyed by the effect's name
#   marker      a compiler-minted declaration or binder is recognised by its spelling
#   discard     a `_` prefix on a binder's spelling stands for "holds nothing"
#   tparam      a type parameter or `Self` has no id and is matched by spelling after the resolver
#   refine      a type refinement's predicate is never walked by the resolver
#   by-name     a declaration is looked up or compared by name with its id in hand
#   mint        (the `mint` rows)
#
# The gate counts these rows and, with --final, fails while there is one. A row leaves this file
# when its site decides by id, never by moving to another ledger.
