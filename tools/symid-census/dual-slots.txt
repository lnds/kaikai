# Type definitions that hold a text slot beside an id slot, and what the text is.
#
#   file  type  why
#
# None of these texts names the thing the id identifies:
#   binder    the place a local is declared: its id and the one copy of the name it was written with
#   op label  an effect or protocol operation's label; an operation has no id of its own
#   origin    the module a declaration or a piece of code comes from (`None`: the root file)
#   emitted   text an emitter spells: a C symbol, a register, a dispatch key, a run-time name
#   tag       a closed tag or a message, not a name
#   key       text another table is keyed by, with the id as its value
ast.kai	Binder	binder
ast.kai	Decl	origin: each declaration's module, beside its id
ast.kai	OpRef	op label: the operation inside the effect `eff` identifies
ast.kai	ProtoImplReg	op label, and origin: the impl's module
ast.kai	ProtoKey	emitted: the dispatch key an impl symbol spells the protocol with; origin
ast.kai	ProtoOpReg	op label, and origin: the protocol's module
ast.kai	ProtoOriginReg	origin: the protocol's module
ast.kai	ProtoTPReg	origin: the protocol's module
ast.kai	RecInfo	origin: the record's module
ast.kai	TrmcStep	emitted: the self function's C symbol, and `cname`, the cell's run-time name or the builtin cons marker (the marker test is a pending-written row)
closure_spec_emit.kai	Beta	key: the specialisation's name, which keys the binders of each pasted copy; `f` is the parameter replaced
driver.kai	ScopeBind	tag: the binder's kind in a `--def` answer (`Param`, `PatBind`, …)
emit_c.kai	ClauseParts	emitted: the enclosing function's C symbol
emit_shared.kai	ClauseInfo	emitted: the enclosing function's C symbol; origin
evidence.kai	Obligation	op label: the operation whose call raised the demand; the id is the receiver it went through
exhaust.kai	XSib	tag: how a missing-case witness prints the constructor with its payload wildcards
fnreg.kai	EFn	emitted: the name the function is emitted under; origin
infer.kai	CallSite	origin: the module the call site is written in
infer.kai	EnvKey	op label: `KOp(effect, label)`
infer.kai	FieldDeclWithHome	origin: the record's module
infer.kai	FieldRec	origin: the record's module
infer.kai	OpEffArity	op label
infer.kai	OpResolution	op label: the operation one call resolved, beside the function it sits in
infer.kai	OpToEff	op label: the label an effect is found by
infer.kai	ResolvedCS	origin: the module the call site is written in
infer.kai	ResolvedRowHole	origin: the module the hole is written in
infer.kai	SumInfo	origin: the sum's module
kai_builtin.kai	KaiBuiltin	emitted: the run-time symbol a declared core builtin's calls bind
kir.kai	KHandlerDecl	emitted: the handler's symbol and its return thunk's
kir.kai	KOp	op label: `KPerform(effect, …, label, …)`
kir_lower.kai	Rename	emitted: the fresh register a shadowing binder took
law_checks.kai	ImplRef	origin: the impl's module
name_uses.kai	NDisp	op label: the operation a dispatcher stands for, between the dispatcher's id and its protocol's
parse.kai	PQName	the parser: a dotted name as the source wrote it, beside the written reference built from it
proto_op_index.kai	OpEntry	op label: the label a protocol is found by
protos.kai	DerivedType	origin: the module the derived functions are declared in
protos.kai	ImplHead	emitted: the dispatch key and the type piece an impl symbol spells; origin
protos.kai	ProtoLaw	tag: the theory (`Functorial`, …) a protocol declares its laws under
purity.kai	Candidate	origin: the function's module
purity.kai	PurityMark	origin: the function's module
purity_traps.kai	TCand	origin: the function's module
rawsafe.kai	RSMark	tag: the site kind, `load` or `store`
scope_view.kai	SvPick	key: a name a selective import picks, bound to the module that exports it (the resolver's own table)
spec_names.kai	SpecName	emitted: the name a specialisation is emitted under (the table that answers `spec_text`)
tailgraph.kai	TgNode	origin: the function's module
tycon_ids_dump.kai	TidName	origin: the declaring module, for a dump
tycon_pat.kai	TPay	origin: the declaring module
tycon_scheme_home.kai	TyHomeEntry	origin: the declaring module
tycon_scheme_home.kai	TyRes	key: the reading module a contested name is resolved from
type_home.kai	TyHome	origin: the declaring module
