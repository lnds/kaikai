# tools/fmt-width-baseline.txt — the line-width ratchet for `kai fmt`.
#
# Measured by tests/fmt_width.sh over examples/fmt/width/. Every value
# is exact: a run that measures worse fails as a regression, and a run
# that measures better fails asking for this file to be updated, so the
# numbers record the width rewrite's progress commit by commit.
#
#   budget    the target line width in columns (docs/fmt-width.md)
#   soft      over-budget lines the writer could have broken
#   soft_max  the widest such line
#   collapse  lines removed relative to the hand-wrapped source
#
# Target for all three counters: 0, at which point FMT_WIDTH_STRICT=1
# becomes the permanent gate.

budget 100
soft 14
soft_max 195
collapse 43
